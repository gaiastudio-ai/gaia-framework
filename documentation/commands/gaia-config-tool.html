/gaia-config-tool

user-facing
Category:
Configuration
Lifecycle phase:
4 -- Implementation

What it does

/gaia-config-tool edits the tools section of .gaia/config/project-config.yaml. The tools section maps adapter categories (such as sast, secret-scan, dep-audit, linter, formatter, and others) to specific provider tools and their configuration. The editor preserves all YAML comments and formatting outside the edited section. Every edit goes through a diff preview and confirmation gate before writing.

When to use it

  • You need to add, remove, or modify entries in the tools configuration section.
  • You set up a new project and need to configure the tools section.

Prerequisites

  • project-config.yaml must exist. Run /gaia-init to create one if missing.

How to invoke

/gaia-config-tool [--category <name>] [--provider <name>]

When --category is given, the editor jumps straight to that category. An unknown category exits with: category '<name>' is not a known adapter category — see /gaia-list-tools.

What it does step by step

  1. Locate project-config.yaml Resolves the configuration file path.
  2. Extract the tools section Reads the current tools block. If the section is missing, offers to scaffold a default.
  3. Present category editor Renders the current category-to-provider mapping as a table and prompts for category and new provider/config. Cross-references the adapter list to surface available providers.
  4. Diff preview and confirmation Shows a unified diff of what will change. You must confirm before anything is written.
  5. Write back Writes only the modified section, preserving all other content byte-for-byte.
  6. Suggest validation Recommends running /gaia-config-validate to confirm the file still passes schema validation.

Inputs

InputSourceDescription
Project configuration.gaia/config/project-config.yamlThe file containing the tools section.

Outputs

OutputLocationDescription
Updated tools section.gaia/config/project-config.yamlThe modified tools configuration.

Example session

> /gaia-config-tool --category secret-scan --provider gitleaks

Current tools configuration:
  deploy:
    provider: script-deploy

Diff preview:
  tools:
    deploy:
      provider: script-deploy
  + secret-scan:
  +   provider: gitleaks

Apply this edit? [y/n]
> y

Tools section updated. Run /gaia-config-validate to verify.

What to run next

  • /gaia-config-validate -- validate the modified configuration file.
  • /gaia-config-show tools -- view the section after editing.

Troubleshooting

tools section not found

The section does not exist in your config file. The command offers to scaffold a default with commented-out adapter categories:

tools:
  # Available adapter categories:
  #   a11y-scanner | dast | dep-audit | deploy | e2e-runner |
  #   formatter | linter | mobile-static | perf-tool | sast | secret-scan
  # Plus the prose-only category (no adapter; direct invocation):
  #   test_runner    -- consumed by /gaia-test-run

Note that tools.aggregation is a reserved key for pipeline-wide SARIF-merge and dedup settings -- it is not a scanner category.

Unknown category

The category you supplied is not in the canonical adapter-category set. Run /gaia-list-tools to see available categories and providers.

Edit cancelled

You chose not to apply the edit. The file remains unchanged.
