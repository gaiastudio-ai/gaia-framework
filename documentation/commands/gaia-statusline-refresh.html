/gaia-statusline-refresh

user-facing
Category:
Configuration
Lifecycle phase:
Any

What it does

/gaia-statusline-refresh unconditionally re-runs the cached install-statusline.sh to bring the statusline runtime at ~/.claude/gaia-statusline/ up to date with the installed plugin version. The installer copies five runtime files using compare-only-if-different semantics, so a refresh is a no-op when the runtime already matches the cached version.

This command exists because /gaia-statusline-enable gates re-installation behind a TTY consent prompt -- which cannot fire from inside Claude Code's Bash tool channel. /gaia-statusline-refresh bypasses that prompt: the explicit slash-command invocation is the consent.

When to use it

  • You upgraded the marketplace plugin and the statusline still shows the old version.
  • You are scripting an automated environment (YOLO mode, CI) and need a known-fresh runtime.
  • You suspect a partial copy or corrupted runtime and want a diagnostic re-install.

Prerequisites

  • The marketplace plugin must be installed. The command resolves the cached install-statusline.sh from the plugin cache. If no cache exists, it refuses with an error directing you to install the plugin.

How to invoke

/gaia-statusline-refresh

What it does step by step

  1. Resolve the cached installer Finds the highest-semver directory under the plugin cache and locates install-statusline.sh within it.
  2. Pre-flight check If no cached installer is found, exits with an error directing you to install the marketplace plugin.
  3. Read pre-install marker Records the current .installed-version marker for no-op detection.
  4. Run the installer Executes the cached install-statusline.sh. The installer copies the five runtime files (compare-only-if-different), writes the version marker, and performs a surgical cache reset.
  5. Report Compares the pre- and post-install version markers and reports either a no-op (already at the latest version) or a successful refresh to the new version.

Inputs

InputSourceDescription
Plugin cache~/.claude/plugins/cache/The cached plugin version containing the installer script.

Outputs

OutputLocationDescription
Updated runtime~/.claude/gaia-statusline/The five runtime files, updated only when they differ from the cached version.
Version marker~/.claude/gaia-statusline/.installed-versionRecords the currently installed version.

Example session

> /gaia-statusline-refresh

gaia-statusline-refresh: refreshed runtime to 1.219.0

> /gaia-statusline-refresh

gaia-statusline-refresh: no-op (already at 1.219.0)

What to run next

  • The refreshed statusline renders automatically on the next prompt cycle. Customize with the GAIA_STATUSLINE_THEME environment variable. See Statusline Reference for details.

Troubleshooting

no cached install-statusline.sh found

The plugin cache does not contain the installer script. Install the marketplace plugin first: /plugin marketplace add gaiastudio-ai/gaia-framework.

Statusline still shows old version after refresh

The settings.json block may be missing. Run /gaia-statusline-enable to ensure the statusline is activated in Claude Code settings.

Hand-edited runtime overwritten

If you have hand-edited ~/.claude/gaia-statusline/statusline.sh, this command will overwrite your changes. Manage refresh by hand instead -- copy the upstream changes you want into your customized runtime.
