/gaia-config-rubric

retired
Category:
Configuration
Status:
Retired (deprecation redirect)

This command is retired

/gaia-config-rubric has been retired. The rubrics top-level property never existed in the v2.0.0 project configuration schema -- the rubric configuration surface was decomposed into two separate sections.

If you invoke this command, it displays a deprecation notice and asks which replacement you intended.

Use instead

What you want to doCommand
Edit the global 5-into-3 severity-to-verdict map /gaia-config-severity
Edit per-gate severity overrides /gaia-config-gates
Validate a rubric file against the schema /gaia-validate-rubric
