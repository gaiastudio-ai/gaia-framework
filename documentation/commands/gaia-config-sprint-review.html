/gaia-config-sprint-review

user-facing
Category:
Configuration
Lifecycle phase:
4 -- Implementation
Arguments:
[get|set|show|clear] [--key <dotted-path>] [--value <v>]

What it does

/gaia-config-sprint-review edits the sprint_review section of .gaia/config/project-config.yaml. This section maps per-stack execution-review commands consumed by the Track B runner in /gaia-sprint-review. The editor preserves all YAML comments and formatting outside the edited section.

Key fields include:

  • playwright_headed -- must be true (foreground-mode enforcement). Setting it to false is rejected.
  • timeout_per_stack -- integer in [30, 3600] seconds.
  • human_confirm -- required or optional.
  • backend_commands.<stack-id>, frontend_commands.<stack-id>, mobile_commands.<stack-id>, etc. -- per-stack execution-review commands.

When to use it

  • You want to configure which test commands run during the sprint-review execution phase.
  • You need to adjust the per-stack timeout or human-confirmation mode.
  • You want to view or reset the sprint-review configuration.

Prerequisites

  • project-config.yaml must exist. Run /gaia-init to create one if missing.

How to invoke

/gaia-config-sprint-review show
/gaia-config-sprint-review get --key timeout_per_stack
/gaia-config-sprint-review set --key backend_commands.backend-python --value "pytest -v"
/gaia-config-sprint-review set --key human_confirm --value required
/gaia-config-sprint-review clear --key backend_commands.backend-python

What it does step by step

  1. Locate project-config.yaml Resolves the configuration file path via the canonical resolver.
  2. Extract the sprint_review section Reads the current block. If the section is missing, show renders the canonical default; set and clear offer to scaffold the default section first.
  3. Validate the proposed edit For set: rejects playwright_headed: false, out-of-range timeout_per_stack, and invalid human_confirm values. Warns on unknown stack identifiers but proceeds.
  4. Diff preview and confirmation Shows a unified diff of what will change. You must confirm before anything is written.
  5. Write back Writes only the modified section through the comment-preserving YAML editor.
  6. Suggest validation Recommends running /gaia-config-validate to confirm the file still passes schema validation.

Example session

> /gaia-config-sprint-review show

sprint_review:
  playwright_headed: true
  timeout_per_stack: 300
  human_confirm: required
  screen_recording_fallback: true

> /gaia-config-sprint-review set --key timeout_per_stack --value 600

Diff preview:
  sprint_review:
    playwright_headed: true
  - timeout_per_stack: 300
  + timeout_per_stack: 600
    human_confirm: required
    screen_recording_fallback: true

Apply this edit? [y/n]
> y

sprint_review section updated. Run /gaia-config-validate to verify.

What to run next

  • /gaia-config-validate -- validate the modified configuration file.
  • /gaia-sprint-review -- run the sprint review that consumes this configuration.
  • /gaia-config-show sprint_review -- view the section after editing.

Troubleshooting

sprint_review.playwright_headed must be true (foreground-mode enforcement)

The schema enforces playwright_headed: true. Headless mode is not supported because the foreground invariant is the reason Track B execution review exists. This value cannot be set to false.

sprint_review section not found

The section does not exist in your config file. The command offers to scaffold a default section with sensible values on first write.

timeout_per_stack out of range

The value must be an integer between 30 and 3600 (seconds). Adjust to a value within this range.

Invalid human_confirm value

Only required and optional are accepted. Any other value is rejected.
